# Task-Scheduler – HTML/CSS/JS-Prototyp

## Starten

1. ZIP entpacken.
2. `index.html` doppelklicken.
3. Der Prototyp läuft lokal im Browser; es wird kein Server benötigt.

## Enthaltene Ansichten

- Dashboard / Kachelansicht
- Timeline / Wochenansicht
- Alle Tasks
- Labels
- Team
- Task erstellen / bearbeiten
- Task-Detailansicht
- Filter-Overlay

## Interaktionen

- Navigation über die Sidebar
- Wechsel Kachelansicht ↔ Timeline
- Neuer Task
- Task bearbeiten
- Task als erledigt markieren
- Bei wiederkehrenden Tasks wird im Detail erklärt, dass nur die einzelne Instanz abgeschlossen wird
- Filter-Overlay
- Textsuche auf dem Dashboard

## Design

Desktop-first, basierend auf dem zuvor aufgebauten Figma-Mockup. Hauptframe ist für 1440×1024 ausgelegt, funktioniert aber auch auf kleineren Bildschirmen.

## Team- und Label-Verwaltung

- Personen erstellen und löschen
- Teams erstellen, Mitglieder auswählen und Teams löschen
- Labels erstellen und löschen
